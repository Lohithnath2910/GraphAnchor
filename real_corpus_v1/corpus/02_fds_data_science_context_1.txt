The Data Science Process, 8 Stages End-to-End A structured lifecycle that converts a business problem into a deployed solution

Data Science Process

Data Science Process Stage 1, Business Objective Every data science project starts by precisely defining the problem to be solved, in business or research terms, not technical terms.

Stage 2, Data Requirement Once the objective is clear, identify what data is actually needed to answer it . Isolate exactly which features, temporal boundaries, and metadata schemas are strictly mandatory to address the business problem.

Data Science Process Stage 3, Data Collection Gather identified data from source systems (ERP, web scraping, IoT, files) Real-world data is rarely clean, rarely in one place, rarely in the right format

Stage 4, Exploratory Data Analysis (EDA) Clean: handle nulls, duplicates, outliers, encoding errors Profile: understand distributions, column types, value ranges EDA can completely reshape or redirect the problem definition

Data Science Process Stage 5, Modeling Choose an algorithm based on the problem type (classification, regression, clustering) Train the model on prepared data; tune hyperparameters for best performance

Stage 6, Evaluation Test the model on held-out data it has never seen, avoids overfitting Metrics: accuracy, precision, recall, F1-score, RMSE depending on problem type Ask: does the output actually answer the original business objective?

Data Science Process Stage 7, Deployment & Monitoring Embed the model in a live application, dashboard, or automated pipeline Monitor performance continuously, real-world data drifts over time. A model that was 92% accurate in testing can degrade silently in production

Data Science Vs Business Intelligence BI and Data Science, Not Competitors, But Collaborators BI handles day-to-day operational reporting, 'What were yesterday's sales by region?' Data Science is brought in for harder, forward-looking questions, 'Which customers are likely to churn next month?' Data Science teams often consume data from BI-maintained data warehouses as one of their input sources BI skills (SQL, dashboards) are a useful foundation before learning Data Science

Prerequisites for a Data Scientist A Data Scientist must find patterns within the data. Before he/she can find the patterns, he/she must organize the data in a standard format. Here is how a Data Scientist works: Ask the right questions. Explore and collect data. Extract the data. Clean the data. Find and replace missing values.

Prerequisites for a Data Scientist Normalize data . Analyze data, find patterns and make future predictions. Represent the result. There are three essential things required to be a data scientist: Curiosity. Common sense Communication skills

Prerequisites for a Data Scientist Curiosity: The ability to ask the right question The entire downstream pipeline depends on problem framing at the start. Ask: What would prove or disprove my assumption? A wrong question, even followed by correct analysis, leads to a useless answer (the most expensive mistake in data science) Curiosity is what drives you to question data that 'looks fine' instead of assuming it is

Prerequisites for a Data Scientist Common Sense Handle incomplete reality creatively Real data is almost never complete, clean, or exactly what was requested Common sense lets you make reasonable, defensible assumptions when data has gaps Recognize when a result 'looks wrong' even if the code ran without errors Prevents building technically perfect models that solve the wrong thing

Prerequisites for a Data Scientist Communication Translate findings into decisions Technical brilliance with poor communication = zero business impact Decision-makers need plain language, not p-values and loss curves. Visualization, storytelling, and stakeholder empathy are communication skills. Often the difference between a data scientist and an influential data scientist

Tools and Skills Needed Programming Languages Python and R are the dominant languages in data science, alongside MATLAB and GNU Octave for more mathematically-oriented work. Statistics and Mathematics Statistics and probability form the conceptual foundation underneath every data science technique, a data scientist must understand these well enough to correctly formulate a problem before reaching for any tool or library.

Tools and Skills Needed Databases and Data Handling SQL: essential for querying structured ETL (Extract, Transform, Load): the skill of pulling data out of source systems, reshaping it, and loading it . NoSQL: needed when handling unstructured or semi-structured data . Big Data Platforms Big data plaforms is suited to storing and processing very large volumes of both structured and unstructured data across clusters of machines.

Simple, readable syntax, easiest entry point for beginners. Largest ecosystem of data science libraries (NumPy, pandas, scikit-learn, Matplotlib, TensorFlow). Used for the full pipeline: data cleaning, modeling, deployment, and web integration. Most in-demand language for data science job roles globally. Covered in Module 5 of this course. Designed specifically for statistical computing and data analysis. Excellent built-in statistical functions; strong for research and academic work. Powerful visualization via ggplot2 library.
